# Contrato de entrada

Acepta lenguaje natural, documentos, adjuntos, enlaces accesibles y artefactos del proyecto. No exige un formulario ni que el usuario conozca los nombres de las skills. Usa primero el contexto disponible; pregunta únicamente por omisiones que puedan cambiar sustancialmente el resultado. Marca `No especificado`, `Ambiguo`, `Requiere confirmación` o `Inferencia` según corresponda. Un dato reportado por el usuario no se convierte en una medición ejecutada por el asistente.

## Información útil

- Diff, commit, PR, rama o archivos y base de comparación.
- Intención, requisitos y comportamiento que debe conservarse o cambiar.
- Contexto de consumidores, datos, versiones y pruebas.
- Riesgos prioritarios y entorno de verificación autorizado.
- Alcance: análisis, comentarios preparados o corrección expresamente solicitada.

La entrada mínima es un cambio o una ubicación que permita identificarlo. Si no se conoce la base o falta parte decisiva del código, limita los hallazgos a lo verificable e identifica el material necesario.
