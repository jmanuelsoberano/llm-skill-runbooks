# Checklist de evaluación

- El análisis sigue una operación con objetivo y población definidos.
- Métricas reportadas, observadas y esperadas están separadas.
- Hipótesis incluyen señal que permitiría refutarlas.
- Comparaciones controlan carga, datos, caches, warmup y errores pertinentes.
- Percentiles no se promedian indebidamente ni se inventan distribuciones.
- El cambio conserva contratos funcionales y valora costo/consistencia.
- Una fuente bibliográfica explica mecanismos sin probar causalidad local.
- Producción y benchmark local se distinguen.
- Experimentos respetan autorización y alcance.
