# Contrato de entrada

Acepta síntoma, objetivo, operación, código, logs, trazas, métricas, profiler, planes, benchmark o archivos adjuntos.

## Mínimo
Operación o recorrido y problema/objetivo de rendimiento.

## Contexto útil
Entorno, versiones, volumen/distribución, concurrencia, tamaño de datos, latencias/throughput/errores, ventana, baseline, límites de recursos y permiso para ejecutar experimentos.

Distingue métricas aportadas de medidas por herramientas. Si faltan datos, propone un experimento refutable y solicita lo que condiciona su validez. No completa percentiles, cargas o factores de mejora inventados.
