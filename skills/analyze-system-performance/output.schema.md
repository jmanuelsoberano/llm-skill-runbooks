# Contrato de salida

Entrega la profundidad solicitada, conservando:
1. Operación, objetivo, entorno y evidencia disponible.
2. Baseline y límites de medición, o datos faltantes.
3. Hipótesis priorizadas con señales de apoyo/refutación.
4. Experimentos ejecutados o propuestos: condiciones y criterio.
5. Cambios recomendados o implementados con efectos funcionales/operativos.
6. Comparación de resultados compatibles, incertidumbre y siguiente decisión.

Cada cifra debe tener unidad, contexto y origen cuando sea relevante. Separa correlación, mecanismo plausible y causa demostrada. Si no se ejecutó benchmark, entrega plan sin presentar expectativas como resultados.
