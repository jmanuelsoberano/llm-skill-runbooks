# Output schema

La salida debe incluir:

1. Resumen de backlog.
2. Issues sugeridos.
3. Issues descartados o no accionables.
4. Dependencias.
5. Preguntas antes de implementar.
6. Orden sugerido de ejecución.

## Formato por issue

```markdown
### Issue #[n]: [Título]

**Tipo:** Feature / Bug / Mejora / Documentación / Investigación / Tarea operativa / Requiere análisis

**Descripción:**

**Contexto:**

**Criterios de aceptación:**

- [ ]

**Prioridad:**

**Etiquetas sugeridas:**

**Dependencias:**

**Preguntas pendientes:**
```
