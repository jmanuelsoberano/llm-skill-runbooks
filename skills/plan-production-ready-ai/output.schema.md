# Contrato de salida

Entrega:
1. Objetivo, alcance, usuarios, riesgos de error y alternativa/baseline.
2. Datos e integración: procedencia, permisos, flujo, aislamiento y dependencias.
3. Evaluación: conjunto/segmentos, particiones, métricas, rúbrica, umbrales conocidos o candidatos y limitaciones.
4. Controles de seguridad, validación, supervisión y fallbacks según el sistema.
5. Despliegue y operación: versionado, observabilidad, costo, responsables y rollback con efectos persistentes.
6. Etapas con criterios de aceptación, pruebas ejecutadas/propuestas y evidencia.
7. Decisiones o datos pendientes.

Separa funcionalidades generativas y ML que realmente apliquen. Distingue estar listo para un piloto de estar validado para producción. No declares calidad, cumplimiento o ahorro sin comprobación correspondiente.
