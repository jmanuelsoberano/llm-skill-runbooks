# Rúbrica de evaluación

Puntúa cada criterio del 1 al 5.

| Criterio | 1 | 3 | 5 |
|---|---|---|---|
| Fidelidad | Inventa o distorsiona | Algunas inferencias confusas | Se apega al transcript |
| Completitud | Omite secciones clave | Cubre lo básico | Extrae todo lo relevante |
| Accionabilidad | No hay próximos pasos | Algunas acciones | Acciones claras con responsables |
| Claridad | Difícil de leer | Aceptable | Muy claro y organizado |
| Reutilización | No sirve para otras tools | Parcialmente útil | Sirve como fuente para issues/docs |
| Manejo de incertidumbre | Afirma sin base | Marca algunas dudas | Marca incertidumbre consistentemente |

## Umbral sugerido

- 24-30: Aprobado.
- 18-23: Requiere mejora.
- Menos de 18: No aprobado.
