# Checklist de calidad

La salida de esta skill es buena si cumple:

- [ ] Tiene un título descriptivo.
- [ ] El resumen ejecutivo explica la reunión sin necesitar el transcript.
- [ ] Identifica participantes y roles cuando sea posible.
- [ ] Extrae temas principales con contexto.
- [ ] Separa decisiones de propuestas.
- [ ] Extrae compromisos accionables.
- [ ] No inventa responsables ni fechas.
- [ ] Marca `No especificado` cuando falten datos.
- [ ] Marca `Inferencia` cuando interpreta.
- [ ] Incluye preguntas abiertas.
- [ ] Identifica riesgos con evidencia.
- [ ] Extrae requerimientos funcionales, técnicos y de negocio si existen.
- [ ] Propone issues razonables.
- [ ] Incluye implicaciones técnicas si hay base para ello.
- [ ] Incluye línea de tiempo cuando hay timestamps.
- [ ] Produce Markdown limpio.
- [ ] Es útil para alguien que no asistió a la reunión.
