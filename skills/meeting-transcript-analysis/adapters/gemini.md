# Adapter: Gemini

## Uso recomendado

Gemini suele responder bien a prompts con objetivo, instrucciones, contexto y formato de salida claramente delimitados.

## Recomendaciones

- Si usas archivos, verifica que Gemini haya reconocido el contenido.
- Para prompts complejos, conserva la estructura con encabezados Markdown.
- Para entradas largas, considera poner el contenido y luego repetir la instrucción final:

```text
Con base en el transcript anterior, genera el documento Markdown siguiendo exactamente la estructura solicitada.
```
