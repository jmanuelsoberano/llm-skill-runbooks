# Adapter: Generic LLM

## Uso

Usa el prompt principal sin depender de herramientas específicas.

## Recomendaciones

- Pega el prompt completo.
- Adjunta o pega el transcript después.
- Si el modelo no puede leer archivos, convierte el archivo a texto.
- Si la respuesta sale incompleta, usa la variante `prompt.chunked-long-transcript.md`.

## Restricciones

- No asumas navegación web.
- No asumas acceso a repositorios.
- No asumas que el modelo puede leer todos los formatos adjuntos.
