# Adapter: Microsoft Copilot

## Uso recomendado

Úsalo cuando el transcript provenga de Teams o Microsoft 365.

## Recomendaciones

- Verifica permisos de archivo.
- Pide explícitamente que use el contenido del archivo adjunto.
- Si Copilot resume demasiado, usa `prompt.full.md` y recalca que necesitas compromisos, decisiones y requerimientos.

## Advertencia

No todos los entornos de Copilot permiten el mismo nivel de acceso a archivos o historial de Teams.
