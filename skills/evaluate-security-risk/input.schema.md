# Contrato de entrada

Acepta petición en lenguaje natural, diff, código, diagrama, configuración sin secretos, propuesta o archivos adjuntos.

## Mínimo
- Sistema o cambio a evaluar.
- Objetivo o preocupación de seguridad, o material suficiente para deducir superficies relevantes.

## Contexto útil, cuando exista
Activos, sensibilidad de datos, identidades, tenants, despliegue, exposición, dependencias/versiones, flujos, controles existentes, decisiones excluidas y pruebas permitidas.

Primero consulta el proyecto. Pide únicamente información cuya ausencia impida valorar un riesgo material o realizar una acción autorizada. Un análisis parcial puede continuar con supuestos explícitos. Si falta el sistema concreto, entrega preguntas de alcance; no produzcas vulnerabilidades confirmadas a partir de una lista genérica.
