# Contrato de salida

Entrega el producto solicitado con extensión proporcional, en español salvo indicación distinta. Los siguientes elementos son criterios de contenido, no títulos ni secciones obligatorios. Respeta el formato y la estructura del usuario.

| Encargo | Resultado |
|---|---|
| Orientación | Recomendación breve de medio/formato, razón y siguiente paso útil; pregunta solo si falta contexto decisivo. |
| Plan o guion | Mensaje central, secuencia y papel de voz/visuales/interacción según el caso; tiempos estimados cuando haya duración objetivo. |
| Revisión | Hallazgos accionables y localizados, priorizados por impacto en comprensión, evidencia o uso; no rediseñar todo por una corrección puntual. |
| Producción | Artefacto en el formato acordado, acompañado solo por notas/materiales requeridos y una breve indicación de comprobaciones. |
| Actualización de esta skill | Cambio trazable de fuentes e instrucciones, versión y evaluación; informar si quedó pendiente por falta de acceso o de repositorio fuente. |

En todos los casos:

- Conserva hechos, alternativas, incertidumbres y estado de las decisiones. Distingue recomendaciones de la serie, adaptaciones al caso y preferencias del usuario cuando afecten una decisión.
- Explica una aplicación parcial o fuera de alcance cuando evite imponer un método inadecuado. Eso no es motivo para abandonar la ayuda.
- Separa material narrado y lectura autónoma cuando sus necesidades difieran. No elimines explicaciones necesarias para que un documento se entienda por sí solo.
- Identifica los supuestos o límites que cambien el uso del resultado. No añadas un reporte de metodología a cada entrega.
- En archivos, indica la ubicación real y qué se verificó. Si no se pudo exportar, renderizar, publicar o medir, dilo; una alternativa no acredita el formato solicitado.

El formato de salida no es siempre Markdown. La extensión del archivo, la disponibilidad de herramientas y el pedido determinan si se entrega PPTX, PDF, HTML, un documento, texto u otro artefacto. Una exposición puede no necesitar diapositivas.
