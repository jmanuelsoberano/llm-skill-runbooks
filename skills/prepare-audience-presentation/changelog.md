# Changelog

## 0.1.0 — 2026-10-15

- Primera versión experimental para orientar, planificar, revisar o producir una presentación según audiencia y propósito.
- Distingue medio, formato y aplicación amplia, parcial o fuera del alcance principal de Never Send The Slides.
- Incluye guía de preguntas breves, materiales para lectura autónoma y límites de exportación según herramientas disponibles.
- Mantiene un núcleo Agent Skills portable, referencias fechadas y procedimiento de actualización explícita desde el repositorio fuente.
- Añade ejemplos sintéticos y casos de comportamiento, alcance y portabilidad. Los casos por sí solos no acreditan ejecución; consultar los resultados registrados en evals/ cuando existan.
- Registra cinco casos de texto, una producción HTML offline, cuatro comprobaciones de selección y descubrimiento nativo en Codex; no acredita ejecución en Claude Code ni exportación PPTX/PDF.
