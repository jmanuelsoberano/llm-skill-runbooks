# Output schema

## Salida esperada

La skill debe producir una propuesta de inicialización en Markdown.

## Secciones recomendadas

1. Resumen del repositorio.
2. Tipo de repositorio identificado.
3. Preguntas pendientes, si existen.
4. Estructura propuesta.
5. Archivos base sugeridos.
6. Decisiones iniciales.
7. Checklist de arranque.
8. Comandos Git sugeridos.
9. Riesgos o puntos de cuidado.
10. Siguiente acción recomendada.

## Valores de incertidumbre

Usar estos valores cuando aplique:

- `Pendiente de definir`
- `Ambiguo`
- `Requiere confirmación`
- `Inferencia`

## Formato

La salida debe ser Markdown claro, reutilizable y fácil de copiar a documentación del repositorio.
