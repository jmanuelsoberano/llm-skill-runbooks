# Ejemplo: repositorio de documentación

## Tipo

Documentación versionada.

## Estructura posible

```text
.
├─ docs/
│  ├─ active/
│  ├─ archive/
│  └─ references/
├─ README.md
├─ PROJECT_CONTEXT.md
├─ STRUCTURE.md
├─ DECISIONS.md
├─ CHANGELOG.md
└─ TODO.md
```

## Notas

- Mantener documentos activos separados de archivo histórico.
- Registrar cambios relevantes.
- Evitar perder contexto importante.
