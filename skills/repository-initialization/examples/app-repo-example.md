# Ejemplo: repositorio de aplicación

## Tipo

Aplicación web, móvil o escritorio.

## Estructura posible

```text
.
├─ frontend/
├─ backend/
├─ docs/
├─ tests/
├─ scripts/
├─ README.md
├─ PROJECT_CONTEXT.md
├─ STRUCTURE.md
├─ DECISIONS.md
├─ CHANGELOG.md
└─ TODO.md
```

## Notas

- Separar frontend y backend si aplica.
- Documentar variables de entorno sin incluir secretos.
- Mantener decisiones de arquitectura visibles.
