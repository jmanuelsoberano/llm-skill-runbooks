# Ejemplo: repositorio de código

## Tipo

Código o aplicación.

## Estructura posible

```text
.
├─ src/
├─ tests/
├─ docs/
├─ README.md
├─ PROJECT_CONTEXT.md
├─ STRUCTURE.md
├─ DECISIONS.md
├─ CHANGELOG.md
└─ TODO.md
```

## Notas

- Documentar instrucciones de ejecución.
- Separar código, pruebas y documentación.
- Registrar decisiones técnicas relevantes.
