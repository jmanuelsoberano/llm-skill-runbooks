# Estructura del Repositorio

Este archivo explica la organización del repositorio y debe actualizarse cuando se agreguen, eliminen o cambien carpetas importantes.

## Árbol inicial sugerido

```text
.
├─ README.md
├─ PROJECT_CONTEXT.md
├─ LLM_GUIDE.md
├─ DECISIONS.md
├─ CHANGELOG.md
├─ TODO.md
└─ STRUCTURE.md
```

## Descripción de rutas

| Ruta | Propósito |
|---|---|
| `README.md` | Entrada principal del repositorio. |
| `PROJECT_CONTEXT.md` | Contexto vivo del proyecto. |
| `LLM_GUIDE.md` | Reglas para colaborar con asistentes o LLMs. |
| `DECISIONS.md` | Decisiones relevantes y su justificación. |
| `CHANGELOG.md` | Cambios importantes del repositorio. |
| `TODO.md` | Pendientes visibles y priorizados. |
| `STRUCTURE.md` | Explicación de esta estructura. |

## Carpetas adicionales

Agregar aquí cualquier carpeta nueva y su propósito.

| Carpeta | Propósito | Estado |
|---|---|---|
| Pendiente | Pendiente de definir | Pendiente |

## Reglas de evolución

- Crear carpetas solo cuando exista una necesidad clara.
- Documentar rutas nuevas en este archivo.
- Registrar decisiones estructurales en `DECISIONS.md`.
- Evitar duplicar información entre archivos.
- Mantener la estructura fácil de entender para una persona nueva.
