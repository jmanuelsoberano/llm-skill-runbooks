# Prompt rápido

Ayúdame a inicializar este repositorio de forma simple y ordenada.

## Datos disponibles

- Tipo de repositorio:
- Propósito:
- Audiencia:
- Tecnologías:
- Restricciones:
- Contenido inicial:
- Frontend/backend separados o integrados:
- Criticidad:
- Dependencias externas:
- Requiere UI:
- Requiere API:
- Preferencias de pruebas:

## Instrucciones

1. Identifica si falta información importante.
2. Clasifica el patrón estructural más probable.
3. Clasifica el perfil de pruebas inicial.
4. Propón una estructura mínima, no sobrediseñada.
5. Indica qué documentos base debo crear, incluyendo `TEST_STRATEGY.md` si aplica.
6. Sugiere qué decisiones conviene registrar desde el inicio.
7. Dame un checklist corto de arranque.
8. Sugiere el primer commit.
9. Indica siguientes pasos.

## Reglas

- Usa Markdown.
- No inventes información que no te haya dado.
- Marca dudas como `Pendiente`, `Ambiguo` o `Requiere confirmación`.
- Mantén la respuesta práctica y accionable.
- No fuerces `frontend/` y `backend/` si no corresponde al patrón.
- No propongas todos los tipos de pruebas por default.
- Ajusta la estrategia de pruebas al riesgo real del repositorio.

## Salida esperada

Devuelve estas secciones, en versión compacta:

1. Resumen del repositorio.
2. Tipo de repositorio identificado.
3. Patrón estructural recomendado.
4. Perfil de pruebas recomendado.
5. Supuestos e incertidumbres.
6. Estructura mínima propuesta.
7. Archivos base sugeridos.
8. Estrategia de pruebas inicial.
9. Decisiones iniciales recomendadas.
10. Checklist de arranque.
11. Primer commit sugerido.
12. Siguientes pasos.
