# Prompt rápido

Ayúdame a inicializar este repositorio de forma simple y ordenada.

## Datos disponibles

- Tipo de repositorio:
- Propósito:
- Audiencia:
- Tecnologías:
- Restricciones:
- Contenido inicial:
- Frontend/backend separados o integrados:

## Instrucciones

1. Identifica si falta información importante.
2. Clasifica el patrón estructural más probable.
3. Propón una estructura mínima, no sobrediseñada.
4. Indica qué documentos base debo crear.
5. Sugiere qué decisiones conviene registrar desde el inicio.
6. Dame un checklist corto de arranque.
7. Sugiere el primer commit.
8. Indica siguientes pasos.

## Reglas

- Usa Markdown.
- No inventes información que no te haya dado.
- Marca dudas como `Pendiente`, `Ambiguo` o `Requiere confirmación`.
- Mantén la respuesta práctica y accionable.
- No fuerces `frontend/` y `backend/` si no corresponde al patrón.

## Salida esperada

Devuelve estas secciones, en versión compacta:

1. Resumen del repositorio.
2. Tipo de repositorio identificado.
3. Patrón estructural recomendado.
4. Supuestos e incertidumbres.
5. Estructura mínima propuesta.
6. Archivos base sugeridos.
7. Decisiones iniciales recomendadas.
8. Checklist de arranque.
9. Primer commit sugerido.
10. Siguientes pasos.
