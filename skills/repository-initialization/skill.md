# Skill: Inicialización de repositorios

## Propósito

Guiar la creación inicial de repositorios versionados en Git para que nazcan con propósito claro, estructura documentada, decisiones registradas y reglas de mantenimiento.

## Casos de uso

- Repositorios de código.
- Repositorios de documentación.
- Repositorios de seguimiento.
- Repositorios de aplicaciones.
- Repositorios de investigación.
- Repositorios de prompts o skills.

## Archivos relacionados

- `input.schema.md`
- `output.schema.md`
- `prompt.full.md`
- `prompt.quick.md`
- `prompt.file-input.md`
- `templates/`
- `examples/`
- `evals/checklist.md`
- `changelog.md`

## Resultado esperado

Al finalizar la aplicación de esta skill, el repositorio debe tener una estructura inicial entendible, documentos base y un primer conjunto de decisiones registradas.
