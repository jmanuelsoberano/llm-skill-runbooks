# Input schema

Acepta texto o Markdown con información de negocio, técnica o de producto.

Contexto opcional:

- sistema;
- repositorio;
- stack;
- restricciones;
- arquitectura actual;
- responsables técnicos.

Opcionalmente acepta hallazgos con IDs y procedencia. Su ausencia no impide usar la skill; no se exige un formato nuevo ni otra skill previa.
