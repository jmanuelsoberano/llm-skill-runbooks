# Contrato de entrada

Acepta reporte de fallo, logs, métricas, trazas, eventos de despliegue, estado, runbooks, hipótesis o archivos adjuntos.

## Mínimo
Síntoma y sistema/operación afectada.

## Contexto útil
Estado activo/resuelto, impacto, cronología y zona horaria, último estado normal, cambios recientes, versiones, integridad de datos, permisos y acciones ya realizadas.

No exige todos los datos para comenzar. Pide o busca primero lo que cambia contención, alcance o seguridad de una acción. Si falta acceso, declara límite y prepara comprobación concreta. Nunca presupone permiso para operar producción.
