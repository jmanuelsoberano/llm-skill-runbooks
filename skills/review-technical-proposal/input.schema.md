# Contrato de entrada

Acepta lenguaje natural, documentos, adjuntos, enlaces accesibles y artefactos del proyecto. No exige un formulario ni que el usuario conozca los nombres de las skills. Usa primero el contexto disponible; pregunta únicamente por omisiones que puedan cambiar sustancialmente el resultado. Marca `No especificado`, `Ambiguo`, `Requiere confirmación` o `Inferencia` según corresponda. Un dato reportado por el usuario no se convierte en una medición ejecutada por el asistente.

## Información útil

- RFC, diseño, propuesta, adjunto o ubicación accesible.
- Objetivo y requisitos confirmados, incluidos contratos y criterios de aceptación.
- Contexto de proyecto, versiones, dependencias y restricciones.
- Cambios propuestos en datos, operación, seguridad o despliegue.
- Profundidad y alcance: revisión, comentarios preparados o edición autorizada.

La entrada mínima es el contenido de una propuesta o su resumen con límites explícitos. Los requisitos ausentes no se completan con reglas de negocio inventadas.
