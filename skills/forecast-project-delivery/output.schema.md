# Contrato de salida

Adapta extensión y formato al usuario o a la plantilla del proyecto. Mantén los elementos del contrato dentro de ese formato, sin crear secciones vacías ni un informe universal. Usa español y conserva identificadores técnicos en inglés. Integra referencias con identificadores junto a la conclusión que sostienen. Señala límites de acceso y distingue resultados observados de verificaciones pendientes.

## Contenido del pronóstico

- Pregunta, fecha de corte, alcance y definición de terminado.
- Datos usados, unidades, calidad y exclusiones.
- Método, supuestos y cálculo o evidencia de ejecución.
- Escenarios, intervalo o percentiles únicamente cuando estén sustentados; etiqueta los escenarios hipotéticos.
- Dependencias, riesgos y sensibilidad del resultado.
- Opciones para actuar y condiciones para actualizar el pronóstico.

La entrega distingue objetivo, pronóstico y compromiso. Si no se calculó nada, no contiene resultados estadísticos atribuidos a una ejecución.
