# Contrato de entrada

Acepta lenguaje natural, documentos, adjuntos, enlaces accesibles y artefactos del proyecto. No exige un formulario ni que el usuario conozca los nombres de las skills. Usa primero el contexto disponible; pregunta únicamente por omisiones que puedan cambiar sustancialmente el resultado. Marca `No especificado`, `Ambiguo`, `Requiere confirmación` o `Inferencia` según corresponda. Un dato reportado por el usuario no se convierte en una medición ejecutada por el asistente.

## Información útil

- Fecha de corte y pregunta: fecha para alcance definido o alcance para una fecha.
- Definición de terminado, unidades y trabajo restante.
- Flujo histórico con periodos y datos faltantes identificados.
- Dependencias, calendario, disponibilidad, cambios de alcance y riesgos.
- Fecha objetivo y decisiones que el pronóstico debe informar.

Con una fecha objetivo y ninguna medición, no existe todavía un pronóstico empírico. Puede devolverse un plan de datos y escenarios de supuestos explícitos.
