# Contrato de entrada

Acepta objetivo de aprendizaje, tecnología/competencia, rol, nivel, recursos, restricciones o archivos adjuntos.

## Mínimo
Tema y resultado deseado, explícito o inferible.

## Contexto útil
Conocimientos previos, disponibilidad, fecha objetivo, acceso a fuentes, preferencias, entorno de práctica y uso previsto.

Si falta nivel o tiempo, plantea un primer tramo adaptable con supuestos y una comprobación inicial. No inventes que la persona dispone de horas o licencias concretas. Una incorporación a un sistema requiere su contexto y otro alcance.
