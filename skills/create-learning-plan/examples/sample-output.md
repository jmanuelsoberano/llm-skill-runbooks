# Salida de ejemplo sintética

## Objetivo
Revisar un flujo asíncrono pequeño y justificar cómo propaga cancelación y errores. Nivel inicial: experiencia en C#; dominio de async aún no comprobado.

| Bloque | Estudio y práctica dentro de dos horas | Criterio de avance |
|---|---|---|
| 1 | Diagnóstico breve y lectura de documentación oficial pertinente; variante de una operación asíncrona | Explicar cuándo se completa y dónde aparece un error |
| 2 | Propagar cancelación entre dos operaciones | Demostrar cancelación solicitada y terminación normal |
| 3 | Comparar errores en operaciones secuenciales y concurrentes | Identificar qué se espera y cómo se observa cada fallo |
| 4 | Revisar un ejemplo nuevo y corregirlo | Justificar cambios y comprobar casos de error/cancelación |

Los recursos exactos deben verificarse para la versión utilizada; este ejemplo no inventa enlaces ni páginas. Revisar al terminar el primer bloque: si faltan fundamentos, reducir el cuarto bloque y continuar después. Completar ocho horas no acredita experiencia de producción.
