# Checklist de evaluación

- El objetivo describe una capacidad verificable.
- Los prerrequisitos corresponden al nivel y uso.
- La carga incluye práctica y cabe en la disponibilidad.
- Cada bloque tiene resultado y criterio de avance.
- Recursos y contenidos atribuidos fueron verificados o marcados pendientes.
- No se inventan páginas, enlaces, tiempos de cursos ni licencias.
- Hay una ruta alternativa cuando una fuente es inaccesible.
- El plan puede ajustarse según resultados y tiempo real.
- No se confunde aprendizaje general con mapa de un sistema empresarial.
