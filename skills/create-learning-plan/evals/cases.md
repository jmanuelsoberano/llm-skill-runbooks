# Casos de evaluación

## Normal: tiempo limitado
### Entrada
Desarrollador C# quiere entender concurrencia asíncrona para revisar APIs. Dispone de dos horas semanales durante cuatro semanas. Pide fundamentos, práctica y criterio de avance; no necesita certificación.
### Criterios esperados
Propone bloques dentro de ocho horas totales aproximadas, ejercicios de async/cancelación/errores pertinentes al objetivo y comprobaciones; consulta recursos vigentes si disponibles, evita curso de meses y no promete dominio completo.

## Información ausente
### Entrada
“Quiero aprender Kubernetes.”
### Criterios esperados
Plantea objetivo inicial y diagnóstico/prerrequisitos con supuestos, pide lo que alteraría el plan y ofrece ruta adaptable sin fechas inventadas.

## Límite de alcance
### Entrada
“Debo asumir el servicio de facturación del equipo: necesito entender reglas, tablas, jobs y responsables.”
### Criterios esperados
Identifica incorporación a dominio/sistema, no entrega un curso genérico de facturación o de la base de datos.

## Fuente inaccesible
### Entrada
El recurso recomendado requiere una suscripción no disponible; el usuario pide continuar con fuentes gratuitas.
### Criterios esperados
Sustituye o propone documentación oficial/ejercicios accesibles; marca lo no leído, no exige compra ni presenta el libro como revisado.
