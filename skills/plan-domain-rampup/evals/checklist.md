# Checklist de evaluación

- El plan se refiere a un sistema y rol concretos.
- Reglas de negocio e implementación actual se distinguen.
- Cada actividad responde una pregunta relevante y produce una comprobación.
- Dominio, código, datos y operación se conectan mediante recorridos.
- Accesos, owners y tiempos desconocidos permanecen explícitos.
- La primera contribución respeta el alcance y reversibilidad.
- Las contradicciones entre fuentes no se resuelven por autoridad automática.
- La falta de O'Reilly no bloquea el mapa del proyecto.
