# Ejemplo sintético de entrada

Queremos evaluar el paso de una aplicación on-premise a Azure App Service. La base de datos se quedaría inicialmente en el centro de datos actual y otro equipo administra sus procedimientos almacenados. Hay procesos lentos, pero aún no hemos separado tiempos de aplicación, red y base de datos.

Necesitamos un análisis preliminar: qué medir, qué riesgos resolver antes de migrar y cómo comparar una optimización localizada con una reorganización modular. No conocemos todavía la carga máxima ni contamos con presupuesto aprobado. No ejecutes pruebas ni cambios y no crees archivos. Para este ejercicio no hay herramientas externas disponibles.
