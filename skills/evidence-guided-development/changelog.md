# Changelog

## 1.1.0 — 2026-09-29 — experimental

- Añade coordinación selectiva de especialistas, sin ciclos ni dependencia obligatoria de O'Reilly.
- Integra evidencia compatible 1.0.0: procedencia, acceso, respaldo y aplicación separados.
- Extrae investigación O'Reilly a una skill autónoma con vía alternativa cuando no está instalada.
- Mantiene entradas mínimas y artefactos de salida; mejora minor compatible.

## 1.0.0 — 2026-09-08 — experimental

- Sustituye `applied-architecture-review` por `evidence-guided-development` para cubrir el ciclo de desarrollo, con profundidad proporcional.
- Cambia el contrato de salida: el artefacto depende de la tarea (código, pruebas, HU, documentación, revisión o análisis). Se incrementa la versión mayor por este cambio incompatible; el estado sigue siendo experimental.
- Añade guías condicionales para código y reglas, datos y contratos, HU/documentación, y conserva arquitectura y rendimiento.
- Migración: instalar la nueva carpeta completa, sustituir invocaciones del nombre anterior y conservar la instalación antigua fuera de los directorios de descubrimiento para evitar duplicidad. Las conexiones MCP no cambian.
- Los informes antiguos conservan su validez como artefactos de la versión anterior; la nueva versión no promete ese formato en todas las tareas.

## 0.1.0 — 2026-09-08

- Primera versión experimental con entrada nativa `SKILL.md` y procedimiento portable para uso manual.
- Análisis aplicado de arquitectura, migración y rendimiento con contexto persistente por sistema.
- Distinción entre catálogo Search, lectura autorizada y acceso opcional a Expert.
- Contratos de entrada/salida, plantilla de contexto y casos sintéticos para evaluar incertidumbre y límites de herramientas.
- La calidad de las recomendaciones debe evaluarse con casos reales; los ejemplos no representan validación en producción.
