# Checklist

- [ ] Distingue catálogo, Answers, pasaje leído e inferencia.
- [ ] La relación de respaldo corresponde a la afirmación y al contexto.
- [ ] No inventa páginas, edición, autores, citas ni herramientas.
- [ ] Answers se usa cuando aporta y se intenta si se pide expresamente; cualquier bloqueo queda visible.
- [ ] Lee contexto suficiente; identifica condiciones y busca objeciones relevantes.
- [ ] Fuente y aplicación al proyecto están separadas.
- [ ] Funciona directamente y devuelve evidencia reutilizable sin invocar EGD.
- [ ] Ante acceso ausente continúa trabajo independiente y mantiene pendientes explícitos.
- [ ] No transmite datos privados innecesarios ni copia extensamente libros.
- [ ] Registra aparte validación estática, pruebas sintéticas y acceso real.
