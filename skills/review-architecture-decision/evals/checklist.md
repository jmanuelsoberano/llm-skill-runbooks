# Checklist de calidad

- [ ] Se conserva el objetivo y el alcance solicitado.
- [ ] Se distinguen hechos reportados, evidencia leída, inferencias y propuestas.
- [ ] Los hallazgos enlazan evidencia pertinente; un enlace por sí solo no acredita una afirmación.
- [ ] Se explicitan supuestos que podrían cambiar la conclusión.
- [ ] Se informa un acceso fallido sin fingir lectura ni bloquear fuentes alternativas.
- [ ] No se afirma haber ejecutado herramientas, pruebas o consultas no realizadas.
- [ ] Funciona sin O'Reilly; no presupone un servicio Expert ni llama recursivamente al coordinador.
- [ ] No publica, modifica sistemas ni comunica a terceros a partir de una solicitud de análisis.
- [ ] Distingue contexto histórico de restricciones actuales.
- [ ] Atributos de calidad se vinculan con mecanismos y escenarios.
- [ ] Examina datos y contratos además de límites de despliegue.
- [ ] Hallazgos accionables tienen evidencia e impacto, no solo preferencias.
- [ ] Considera reversión y migración con sus límites reales.
