# Contrato de entrada

Acepta lenguaje natural, documentos, adjuntos, enlaces accesibles y artefactos del proyecto. No exige un formulario ni que el usuario conozca los nombres de las skills. Usa primero el contexto disponible; pregunta únicamente por omisiones que puedan cambiar sustancialmente el resultado. Marca `No especificado`, `Ambiguo`, `Requiere confirmación` o `Inferencia` según corresponda. Un dato reportado por el usuario no se convierte en una medición ejecutada por el asistente.

## Información útil

- Pregunta o decisión que debe comunicarse, audiencia y estado conocido.
- Opciones consideradas, restricciones y criterios relevantes.
- Contexto del sistema, documentos o hallazgos disponibles.
- Consecuencias, incertidumbres, fecha límite y proceso de aprobación si existen.

La entrada mínima es una decisión o pregunta y suficiente contexto para delimitarla. Si faltan opciones o evidencia, produce un borrador explícitamente condicionado e identifica lo que falta para decidir.
