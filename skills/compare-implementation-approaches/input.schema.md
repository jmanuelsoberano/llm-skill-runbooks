# Contrato de entrada

Acepta lenguaje natural, documentos, adjuntos, enlaces accesibles y artefactos del proyecto. No exige un formulario ni que el usuario conozca los nombres de las skills. Usa primero el contexto disponible; pregunta únicamente por omisiones que puedan cambiar sustancialmente el resultado. Marca `No especificado`, `Ambiguo`, `Requiere confirmación` o `Inferencia` según corresponda. Un dato reportado por el usuario no se convierte en una medición ejecutada por el asistente.

## Información útil

- Comportamiento a implementar, invariantes y aceptación.
- Alternativas propuestas o decisión que requiere opciones.
- Código, contratos, stack/versiones y patrón actual.
- Carga, fallos, restricciones operativas y evidencia existente.
- Alcance autorizado: comparación, experimento o implementación.

La entrada mínima permite entender el comportamiento y al menos una alternativa. Cuando faltan restricciones decisivas, produce una comparación condicionada y preguntas concretas.
