# Versionado

Usa versionado semántico:

```text
MAJOR.MINOR.PATCH
```

## Patch

Cambios compatibles y menores.

Ejemplos:

- corregir typo;
- aclarar instrucción;
- mejorar redacción;
- ajustar ejemplo sin cambiar contrato.

## Minor

Cambios compatibles que agregan capacidad.

Ejemplos:

- nuevo prompt alternativo;
- nueva sección opcional;
- nuevo adaptador;
- nueva prueba.

## Major

Cambios incompatibles.

Ejemplos:

- eliminar sección obligatoria;
- renombrar campos de salida;
- cambiar Markdown a JSON;
- cambiar el significado de una tabla.

## Changelog

Toda skill debe tener `changelog.md`.
