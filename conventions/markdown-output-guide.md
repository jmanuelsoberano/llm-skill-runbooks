# Guía para salidas Markdown

## Objetivo

Las skills deben generar Markdown que sea:

- legible por humanos;
- útil para seguimiento;
- fácil de convertir a otros formatos;
- suficientemente estructurado para alimentar otra skill.

## Reglas

1. Usa encabezados jerárquicos.
2. Usa tablas para compromisos, decisiones, riesgos e issues.
3. No uses tablas excesivamente anchas si el contenido es narrativo.
4. Marca explícitamente información faltante.
5. Usa IDs para acciones o tareas.
6. Evita mezclar conclusiones con inferencias sin etiquetar.

## Valores recomendados

### Nivel de certeza

- Alta
- Media
- Baja

### Prioridad

- Alta
- Media
- Baja

### Estado

- Pendiente
- En progreso
- Requiere confirmación
- Bloqueado
- Completado

### Tipo de issue

- Bug
- Feature
- Mejora
- Documentación
- Investigación
- Tarea operativa
- Requiere análisis
