# Workflow: De transcript a documentación

## Objetivo

Usar una reunión como fuente para documentación interna.

## Flujo

```text
Transcript
  → meeting-transcript-analysis
  → extracción de información documental
  → página Markdown / wiki / docs
```

## Secciones útiles del análisis

- Contexto general.
- Información útil para documentación futura.
- Glosario.
- Requerimientos.
- Decisiones.
- Preguntas abiertas.

## Reglas

- No documentes como verdad algo que fue solo una propuesta.
- Marca decisiones pendientes.
- Conserva fecha y fuente de reunión.
- Si hay reglas de negocio, identifica evidencia.
