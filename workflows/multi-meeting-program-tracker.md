# Workflow: Seguimiento de varias reuniones

## Objetivo

Consolidar varias reuniones de un proyecto en una visión de programa.

## Flujo

```text
Múltiples transcripts
  → meeting-transcript-analysis/prompt.multi-transcript.md
  → síntesis consolidada
  → roadmap / backlog / riesgos
```

## Resultado esperado

- temas recurrentes;
- decisiones acumuladas;
- compromisos globales;
- riesgos comunes;
- contradicciones;
- dependencias;
- roadmap sugerido;
- backlog consolidado.

## Cuándo usarlo

- Proyectos con muchas reuniones.
- Seguimiento semanal.
- Discovery de producto.
- Migraciones o integraciones complejas.
